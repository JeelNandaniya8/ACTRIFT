03 / QUICKSTART

Run on your machine.

Python 3.10+ and a supported Playwright browser.

git clone https://github.com/JeelNandaniya8/GHOSTDIFF.git actrift
cd actrift
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m playwright install chromium
actrift demo --out demo-report

Open demo-report/observatory.html. On Windows, activate using .venv\Scripts\activate.

Evidence, not guarantees.

ACTRIFT is a bounded research preview. Use only disposable local applications and synthetic data. Request filtering is not a security sandbox. Independent audit and broad production validation remain open.
