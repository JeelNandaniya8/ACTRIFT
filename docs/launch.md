# ACTRIFT launch

ACTRIFT (formerly our GHOSTDIFF project) is a local-first browser behavioral regression research preview. The prior v0.7.0 was published as ghostdiff-lab; the renamed v0.8.0 must pass fresh CI and publication gates before announcement.

Suggested title: Show HN: ACTRIFT – Git diff for observed browser behavior

Suggested text: I built ACTRIFT to compare what local web applications do, not just what their source code looks like. It explores bounded user journeys, compares observable outcomes, freezes repeatable observations as contracts, and reports evidence of regressions. It runs locally without a required model API. It is a research preview, not an audited sandbox or proof of correctness. I'd welcome independent reproducible bug reports and feedback.
