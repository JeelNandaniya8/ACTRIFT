## Research preview

GHOSTDIFF compares repeatable, observable browser journeys across disposable local web applications.

- Persistent baseline contracts and candidate-only regression verification.
- Generated unittest suite for protected observations.
- Interactive behavioral journey tree with repeated evidence.
- Expanded bounded exploration and explicit coverage limits.
- Synthetic and pinned upstream-example benchmark harnesses.
- Wheel and source distribution.

This prerelease is experimental. Exact-name matching, limited interactions, bounded depth, dynamic content, backend state and network isolation constrain coverage. The benchmarks include deliberately planted defects; they do not establish general detection accuracy or real-world historical regression performance. No mandatory model API is required.

Install the attached wheel with pip, then run python -m playwright install chromium and ghostdiff demo.
