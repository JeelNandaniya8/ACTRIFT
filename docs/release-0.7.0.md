# GHOSTDIFF 0.7.0 Git and context intelligence preview

Static local Git revision automation, source hunk correlation, context-aware rename hypotheses, htmx historical integration evidence, reviewed JSON configuration, optional reverse exploration and explicit native form actions. macOS and Windows Chromium smoke gates accompany existing Linux browser coverage.

This preview does not run arbitrary builds, infer source causality, prove semantic equivalence or certify production safety. Independent review and broader real-world validation remain open. Publish only after exact-revision test and security workflows pass and findings have been reviewed.
