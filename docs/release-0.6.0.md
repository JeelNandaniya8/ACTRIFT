# GHOSTDIFF 0.6.0 evidence intelligence preview

Stable observation fingerprints, conservative review-only rename hypotheses, first-divergence diagnostics and bisection across supplied local revisions. GHOSTBENCH gates summarize the existing historical and synthetic benchmark reports without claiming a representative accuracy rate.

This is a research preview. The bisect command does not provision or attest Git commits, matching does not prove semantic equivalence, and diagnostic leads do not prove source causation. Independent review and broad production validation remain open. Publish only after the exact revision's CI and security checks have succeeded and findings have been reviewed.
